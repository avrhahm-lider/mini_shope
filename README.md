
# Mini shop

## הרצת הפרויקט 

להוריד את הפרויקט ואז בתיקית הפרויקת להריץ `npm install` ואז `npm run dev`

## Hooks
### useFetch

hook שמקבל URL ועושה בקשת fetch מקבל את הנתונים כי זה אסינכרוני ושולח יש שם useEffect שבדוק שהURL השתנה כדי למנוע ריצה מיותרת

## Context 
### ThemeMode
יצירת context שהיצירה מכילה מצב ופונקציה להליף היא מחליפה את מצב התאורה ומתבצעה שימוש בcss

## Zustand
### favoritStor
הסטור מכיל רשימה של הfaivorit פונקציה להסרה ופונקיה להוספה של מוצר
